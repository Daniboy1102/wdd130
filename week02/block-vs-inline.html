Task 1: Swap Block and Inline Elements

In the HTML of this document, change this div element to a span element.

What happens to the layout? Does it still take up the full width?

When the div is changed to a span, it no longer takes up the full width of the page.

Task 2: Nesting Inline in Block

A paragraph <p> element (block) with a <span> element, <strong> element, and <em> element.

Add another inline element like <em> or <strong> inside the paragraph. Observe how it flows within the line.

Inline elements flow naturally within the paragraph and do not start on a new line. They only affect their own text.

Task3: Nesting Block in Inline

This div is inside a span (error).

What error or layout issue do you see? Why does this happen?

The layout breaks or the browser automatically closes the span. This happens because block-level elements are not allowed inside inline elements.
